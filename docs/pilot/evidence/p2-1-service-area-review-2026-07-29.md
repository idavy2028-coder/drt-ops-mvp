1. `docker-compose.pilot.yml` 的默认项目没有运行；P1 实际环境使用管理端 `127.0.0.1:5174`、API `127.0.0.1:18081`，且 API 连接 `drt_ops_pilot_bootstrap`。核验时已通过容器挂载、健康端点和页面数据交叉确认，未误启空环境。
2. 同一 PostgreSQL 容器中的 `drt_ops` 是旧“望京示范区”库，不是本次试点库。首次误查只执行了 `SELECT`，结果已判为无效；后续所有 P2-1 数据结论均来自 API 实际连接的 `drt_ops_pilot_bootstrap`。
3. 当前没有可用的系统管理员浏览器会话，仓库记录的两组本机测试凭据也不适用于持久化试用库。未重置账号、未猜测更多密码。
