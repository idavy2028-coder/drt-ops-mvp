恢复真实验收前，每台设备至少需提供以下私密现场证据：

1. 终端当前服务器地址和端口配置已指向本次验收端点；不得在公开报告中记录完整地址。
2. 设备在约定窗口内确实执行了上电、重启或网络重连。
3. 终端或厂商平台能够提供该窗口内的 TCP 连接尝试结果；失败时记录网络错误码或原因。
4. 先选一台设备完成 TCP 建连和注册，再按顺序扩展到其余三台；任何一台失败立即暂停。
5. 注册后继续验证管理员自动激活、鉴权、位置和报警；附件链路保持禁用。
