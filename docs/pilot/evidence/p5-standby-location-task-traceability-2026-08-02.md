# 待命位置上报与任务追溯修复验证记录（2026-08-02）

## 修复范围

- 待命位置上报候选车辆仅显示 `IDLE` 状态。
- 后端对无任务关联的 `MANUAL_REPORT` 在同一事务中加锁复核车辆状态；非 `IDLE` 返回 HTTP 409，且不写位置事件、快照或审计记录。
- 位置历史明确标识任务筛选条件，并在事件上显示任务短编号及任务页深链；无关联事件明确标识“无任务关联”。
- 任务页支持通过 `taskId` 查询参数精确选中任务。

## 测试先行证据

| 项目 | RED 证据 | GREEN 证据 |
| --- | --- | --- |
| 候选过滤 | 候选接口返回 3 辆车，含 `DISPATCHED` | 仅返回 2 辆 `IDLE` 车辆 |
| 写入门禁 | `DISPATCHED` 车辆无任务 `MANUAL_REPORT` 返回 201 | 返回 409，事件数、审计数、状态与快照不变 |
| 前端候选与空态 | 忙碌车辆可见，且无空闲车辆不提示 | 忙碌车辆隐藏，空态明确且提交按钮禁用 |
| 任务追溯 | 时间线没有任务链接 | 显示短编号深链；无关联事件显示固定提示 |
| 任务定位 | `taskId` 指向非首条任务时仍选中首条 | 精确选中查询参数指向的任务 |

## 浏览器验收建议

1. 以调度员身份打开“位置历史”，确认待命车辆下拉框只包含空闲车；所有车均忙时显示空态且不能提交。
2. 对非空闲车直接调用或使用旧页面提交待命位置，确认提示“当前车辆正在执行或等待任务，不能上报待命位置”。
3. 查询一条有关联任务的位置事件，点击“任务 <短编号>”，确认任务页选中对应任务；同时确认页面未显示乘客姓名、电话或订单详情。
