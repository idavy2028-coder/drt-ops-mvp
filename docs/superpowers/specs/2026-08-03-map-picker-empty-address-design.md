# 地图点选空地址保留设计

## 目标

地图点选坐标时，若地址输入框为空，前端不得再写入“地图点选位置”这一通用文案；若调度员已输入地址，则继续保留其输入内容。

## 范围与边界

- 仅调整 `AddressCoordinateField` 的地图点击回写逻辑。
- 经纬度继续以六位小数保存，已选虚拟站点继续在地图点选后清除。
- 不自动把推荐虚拟站点名称写入地址，也不增加提交拦截或改动后端的坐标地址回退规则。
- 地址留空后，现有后端仍可按既有规则以坐标作为地址回退；该行为不属于本次修复范围。

## 方案选择

采用方案 A：将地图点击回写的地址设为输入框的去首尾空白后的值。空输入框因而回写为空字符串，而非“地图点选位置”。

该方案最小化变更，避免把未由调度员确认的站点名或描述写入订单，同时保持已有手工地址和坐标、站点联动不变。

## 验收标准

1. 空地址地图点选后，组件发出的 `update:modelValue` 含空字符串地址和选中坐标。
2. 已输入地址地图点选后，组件继续发出该输入地址。
3. 地图点选仍清除 `virtualStopId`，且坐标精度逻辑不变。
